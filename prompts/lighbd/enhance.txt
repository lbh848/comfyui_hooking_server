PURPOSE

Fill the supplied character-by-time table sparsely with outfit and hairstyle image tags. The server expands your checkpoints to the right; you do not output the table or repeat unchanged tags at every C anchor. Characters are already resolved. Do not select scenes or change identities.

CONTEXT AND CHRONOLOGY

Use the fixed canonical roster exactly. Read the full source semantically, including who owns or wears each garment and the chronology of dressing, removal, replacement and hair arrangement. Preserve established garment identity, color and material when a later mention is shorter. An unclothed narrative state must not acquire default garments.

The source passages and empty table columns share the same Cxxx anchor IDs in chronological order. Record the resulting persistent outfit/hair state at each C anchor boundary, after changes established in that passage. Establish the complete state for every canonical character in the first supplied C anchor, including that passage's changes; then emit only later changed aspects at their own C anchor. Track each person independently, even when absent from a later image. Never move a later change into an earlier column. SPARSE TAG CHECKPOINTS

Each person has only `outfit` and `hair`, each a comma-separated English image-tag string. `outfit` describes the complete current wardrobe, accessories and persistent garment arrangement/coverage; `hair` describes the complete current hair appearance and arrangement. Hair accessories belong to outfit. Do not include face, expression, pose, camera, background, person-count tags or transient actions. Determine the coherent state first, then express it as compact established image tags using the established Danbooru vocabulary.

Both fields are required for every person at the first C anchor. Afterward omit unchanged fields, people and entire C anchors. When a field changes, supply its complete resulting tags, not a delta, action instruction or only the added item. The server replaces that field and copies it rightward until its next explicit checkpoint; outfit and hair propagate independently. Keep all still-worn items when a coat is removed, and remove the coat's worn tags; opening a coat leaves it worn. A removed garment is no longer worn even when held. Retain source-established exposure using suitable state tags; do not add garments or concealment. An explicitly empty string clears a field, whereas an omitted field inherits; never use an empty field to mean unchanged or unknown. A windblown braid remains braided; untying it produces a complete loose-hair state. Mere mention, pose or ordinary prop contact creates no checkpoint.

Use the actual first supplied C anchor. Output initial tags and changed checkpoints only, in column order. No table, status/event prose, commentary or extra fields.
