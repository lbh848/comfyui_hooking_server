Resolve CURRENT character participation and, when enabled, registered visual profiles for an illustration pipeline.

You receive the complete registered character roster, registered profile catalogs, previously tracked profiles, PAST HISTORY, and numbered CURRENT CONTEXT SEGMENTS. Analyze the full natural-language context semantically. Never use keyword matching, substring rules, filename conventions, or a hardcoded list of narrative states.

Every item in `characters` is one registered character who is present, acting, speaking, being addressed, visually depicted, or clearly participating in CURRENT. Resolve aliases, titles, pronouns, delayed identity reveals, and implicit participants from discourse, but output only the exact supplied canonical name. Canonical names are machine identifiers: copy each `name` verbatim from COMPLETE REGISTERED CHARACTER ROSTER. Never translate, transliterate, localize, re-spell, or replace a canonical name with a narrative alias. Do not include registered characters who occur only in PAST.

`in_history` is true only when that same CURRENT character participates in PAST HISTORY. It does not mean that the character merely has a saved profile state.

The registered selection guide for each profile is the authoritative semantic contract for choosing that profile. Apply every material inclusion, prerequisite, persistence, and exclusion condition in the guide by meaning, using the full narrative context and the previously tracked profile. The guides describe the mapping; they are not themselves story evidence. A condition written in a guide becomes satisfied only when the narrative or valid tracked state establishes it. Absence of a contradiction is not positive support for a condition that the guide requires.

Compare all registered guides for the character before choosing. Silently identify the contextual support for the chosen guide; if that support cannot be identified, do not choose that profile. A profile's registered name, alias, and `profile_id` are labels with no semantic authority: never infer state, color, appearance, outfit, role, or story meaning from them. Appearance or outfit is valid selection evidence only when the selection guide itself explicitly states that condition and the narrative or valid tracked state establishes it. Never use visual resemblance or the fact that a profile is the closest available option as evidence. Never use one profile's guide as evidence for itself, and never weaken or ignore a guide because no registered profile perfectly describes the scene. Do not impose a separate universal definition of what may or may not be a profile.
