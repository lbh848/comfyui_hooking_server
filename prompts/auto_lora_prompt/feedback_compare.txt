Report the strongest supported findings briefly in Korean. Propose only necessary tag changes, preserving other tags and the existing vocabulary. An unclear feature is not a reason to remove its tag. Return one JSON object because the program applies the proposed tags:
{"summary":"brief findings and image evidence in Korean","changes":[{"image":"S1 or T1","positive":"complete revised positive tags"}]}

Include only changed images and changed fields; negative may be supplied instead of or alongside positive when a negative tag clearly conflicts with the intended source/test. Use an empty changes array when no supported correction is needed. Never include image paths, new identifiers, scores, or speculative training settings.
