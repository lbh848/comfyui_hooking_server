SoyaComfy — macOS 시작 가이드
================================================================


0. 사전 필수 패키지 설치 (미설치 시 앱 실행 불가)
----------------------------------------------------------------

터미널(Terminal)을 열고 다음 명령어를 순서대로 실행합니다.

    xcode-select --install      (Git 설치 포함)
    brew install ffmpeg         (영상 후처리에 필요)

Homebrew가 설치되어 있지 않다면, 먼저 brew.sh 를 참고하여 설치해 주시기
바랍니다.


1. 앱 이동 및 Quarantine(격리) 속성 해제
----------------------------------------------------------------

SoyaComfy.app 을 Applications(응용 프로그램) 폴더로 이동한 후, 터미널에서
아래 명령어를 한 번만 실행합니다.

    xattr -dr com.apple.quarantine /Applications/SoyaComfy.app

본 앱은 ad-hoc 서명만 적용되어 있으며 Apple의 공증(Notarization)을 받지
않았습니다. 따라서 이 과정을 거치지 않으면 macOS의 Gatekeeper가 실행을
차단합니다.

참고: macOS 15(Sequoia)부터는 '우클릭 → 열기'를 통한 우회가 불가능합니다.
반드시 위 xattr 명령어를 사용하거나, 시스템 설정 > 개인정보 보호 및 보안에서
'확인 없이 열기(Open Anyway)'를 클릭해야 합니다.


2. 앱 실행
----------------------------------------------------------------

SoyaComfy를 실행하면 터미널 창이 열리며 초기 설정이 시작됩니다.

최초 실행 시 환경 구축을 위해 약 2.3GB의 데이터를 다운로드하므로 5~15분 정도
소요됩니다. (Python 환경 1.7GB, 모델 0.44GB, 영상 도구 0.17GB)

준비가 완료되면 웹 브라우저에서 다음 주소가 자동으로 열립니다.

    http://127.0.0.1:8189/

두 번째 실행부터는 다운로드 과정 없이 즉시 시작됩니다.


3. 데이터 저장 경로
----------------------------------------------------------------

모든 사용자 데이터는 다음 경로에 저장됩니다.

    ~/Library/Application Support/SoyaComfy

환경 설정, API Key, 작업물, 모델 파일 등이 모두 이 폴더에 보관되므로, 앱을 새
버전으로 업데이트하더라도 기존 데이터는 안전하게 유지됩니다.

주의: ComfyUI 본체는 초기 설치에 포함되어 있지 않습니다. 앱 실행 후 웹 UI의
설치 탭에서 별도로 설치해야 하며, 이 과정에서 추가적인 디스크 용량이
필요합니다.


4. 앱 삭제 및 완전 제거
----------------------------------------------------------------

시스템에서 완전히 제거하려면 다음 두 경로의 항목을 삭제하십시오.

    /Applications/SoyaComfy.app                 (앱 본체)
    ~/Library/Application Support/SoyaComfy     (사용자 데이터)


5. 트러블슈팅 (문제 해결)
----------------------------------------------------------------

"앱이 손상되었기 때문에 열 수 없습니다" 오류 발생 시:
    1단계의 xattr 명령어를 실행하여 quarantine 속성을 정상적으로 해제했는지
    확인해 주십시오.

"먼저 설치해야 하는 것이 있습니다" 메시지 발생 시:
    0단계의 Git 또는 FFmpeg이 설치되지 않은 상태입니다. 가이드의 명령어를 통해
    필수 패키지를 먼저 설치해 주십시오.

앱 실행 시 터미널 창이 열렸다가 즉시 닫히는 경우:
    닫히기 전 터미널에 출력된 마지막 메시지를 확인해 주십시오. 대부분 네트워크
    연결 문제일 가능성이 높습니다.

"8189 포트를 이미 사용 중입니다" 메시지 발생 시:
    이미 SoyaComfy가 백그라운드에서 실행 중이거나 다른 프로세스가 해당 포트를
    점유하고 있습니다. 기존 프로세스를 종료한 후 다시 실행해 주십시오.
