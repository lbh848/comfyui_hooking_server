MOSS TAG-TO-SENTENCE CAPTION FORMAT
Convert the verified supplied tags into fluent, complete natural-language English sentences formatted for MOSS's natural-language text encoder. DO NOT re-caption the image from scratch. Produce a single paragraph of plain sentences—not Danbooru/booru tag lists, not layout JSON, not bounding boxes or coordinates, not bullet points, and not conversational meta-framing (never start with "This image shows...", "An illustration of...", "A drawing of...", or "In this picture..."). Start directly with the subject or scene.

1. Tag-grounded conversion (DO NOT re-tag from scratch):
   - Treat the supplied tag list ({etc}, or the supplied role prompts in test setup) as the primary content inventory to refine and rewrite into natural English sentences—never discard the supplied tags to write a brand-new free-form VLM image description.
   - Use the attached image ONLY to verify the supplied tags: drop tags that clearly contradict the image (wrong color, wrong garment, unseen item), resolve conflicts between competing tags by keeping the side that matches the image, and determine correct subject ownership and spatial/physical relations.
   - Preserve EVERY surviving image-verified content detail from the supplied tags (appearance, clothing, accessories, pose, action, expression, gaze, framing, and background). Do not drop verified tags merely to summarize, and do not invent extra objects, background story, or unprompted details beyond the retained tags and minimal connecting grammar needed to form natural sentences.
2. Zero Danbooru tags, metadata, or triggers: Completely convert or omit all Danbooru/booru shorthand and metadata. Never emit raw count/subject tags (1girl, 1boy, 2girls, 1other, solo, multiple girls), underscore-joined tags (long_hair, blue_eyes, looking_at_viewer), rating labels (safe, sfw, general, sensitive, questionable, nsfw, explicit), quality/score/year tags (masterpiece, best quality, highres, absurdres, newest, 2024), artist names, character proper names, franchise/copyright names, original, signatures/watermarks, or emphasis weights ((word:1.2), [word], {word}). Never add a LoRA trigger word; the application prepends the trigger separately.
3. No art style, rendering technique, vibe, atmosphere, or figurative comparisons (MANDATORY):
   - Art style and rendering are controlled separately (by the trigger and model), NEVER by caption text. Drop every spaced or underscored art-style, medium, or rendering tag/phrase from the supplied list and never introduce new ones: omit medium/format (anime style, anime_style, manga style, digital illustration, illustration, drawing, painting, watercolor, oil painting, sketch, ink drawing, line art, pixel art, 3d render, cg), brushwork/linework (thick outlines, clean lines, rough lines, sketchy linework, painterly, visible brushstrokes, impasto), shading/rendering (cel shading, soft shading, flat color, gradient shading, glossy rendering, realistic, semi-realistic, stylized, cartoonish, chibi), and palette/stylistic lighting labels (pastel palette, muted colors, vibrant colors, warm color scheme, cool tones, dramatic lighting, soft lighting, cinematic lighting, film grain, bloom).
   - Never use abstract vibes, atmosphere, mood, aura, personality, or figurative/metaphorical comparisons: image models interpret concrete nouns literally and will hallucinate those objects into the image. Drop or rewrite any figurative/mood wording and never write similes, metaphors, or animal/object comparisons (for example, NEVER write "a girl with a fox-like vibe", "a fox-like aura", "cat-like gaze", "doll-like face", "angelic presence", "wolfish grin", "fiery aura", or "icy stare"—mentioning "fox-like" causes the model to draw an actual fox). Never write abstract atmosphere/mood words (such as "mysterious atmosphere", "dreamy vibe", "cozy mood", "melancholic feel", "ethereal aura", "playful energy", "elegant demeanor", "serene vibe", "aesthetic").
   - Express retained tags as literal physical features only: write concrete visible cues such as "narrow, upturned eyes and a slight smirk" instead of "a fox-like vibe", and concrete physical setting details from retained tags such as "sunlight coming through a window onto a wooden table" instead of "a warm, cozy atmosphere".
4. Sentence structure and direct phrasing: Weave all retained tags into concise, natural English sentences in a single paragraph with no line breaks. Convert booru framing, camera, pose, and gaze tags into natural English (for example, `cowboy_shot` -> "seen from the thighs up", `looking_at_viewer` -> "looking toward the viewer", `from_below` -> "viewed from a low angle"). Convert subject/count tags naturally using plain nouns: use "girl" or "woman" for female subjects (and "old woman" when visibly elderly), "boy" or "man" for male subjects (and "old man" when visibly elderly), plural forms such as "two girls", "two women", or "old women" as appropriate, and "person" when gender is ambiguous. Never write "young girl", "young boy", "little girl", or "little boy"—use plain "girl" or "boy" instead. For scenes without people, describe the retained object/scenery directly without inventing a person. Do not invent an extra visible person for a first-person POV viewpoint.
5. Multi-subject attribution: When the image and tags show multiple distinct people or subjects, use the image to assign each retained tag to its actual owner using natural spatial references (for example, "On the left, a woman with short black hair... On the right, a man in a dark coat...") so attributes never bleed across subjects.
6. Conflict resolution and deduplication: Resolve genuine attribute conflicts from the image while keeping visibly compatible retained traits (such as explicit multicolored hair, heterochromia, or multiple layered garments). Deduplicate generic+specific tag pairs when they refer to the same item (convert `bow, white_bow` into "a white bow", not "a bow and a white bow"). Keep every distinct verified garment and accessory from the supplied tags (belts, buckles, ribbons, trim, jewelry, headwear, footwear, layering).
7. Visible legible text: If the supplied tags contain verified, legible text clauses that match the image, include them naturally in exact quotes (for example, 'A sign behind her reads "OPEN".'). Do not guess or translate unreadable text, and do not add OCR coordinates.
8. Output contract: Return the complete single-paragraph caption in the requested "positive" JSON string field with no line breaks, markdown fences, commentary, or extra keys.
