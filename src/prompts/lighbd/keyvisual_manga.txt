PURPOSE

Create exactly one standalone Key Visual manga page that represents the current narrative's central event, relationship or contrast. Choose its source-supported sequence independently of the assigned ordinary page anchors. This is an additional representative manga page, not a single-image cover illustration.

SOURCE AND CONTINUITY

OUTPUT

Add one keyvis object to the same JSON root as scenes. It has no slot and uses the same layered manga schema as an ordinary page: image_size, page, panels and optional cross_panel_actors. Choose its size from the supplied page_size_options and write all bboxes in that coordinate space. Follow the active panel-count and composition-hint rules, including a distinct composition ID in summary when hints are enabled. Each composition must be unique across both scenes and keyvis in this request. The server generates the whole page as one MOSS multi_panel image.
