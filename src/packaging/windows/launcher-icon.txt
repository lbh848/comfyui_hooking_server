Comfy Workshop launcher icon

Source artwork: 1794778361_c96c50.png (user-provided image).
Bundled original: launcher-icon.png, 337 x 337 px, RGBA.
The PNG is an unchanged copy of the source, including its transparency.
No image generation, cropping, redrawing, background removal, or retouching.
Windows icon: launcher.ico, containing 16, 24, 32, 48, 64, 128 and 256 px sizes.
The ICO applies a rounded-square alpha mask with a 34 px corner radius
on the 337 x 337 px source (about 10% of its width). Existing transparency
is retained. The source PNG remains unchanged.
Mask edges use 4x supersampling with Lanczos downsampling, multiplied by
the source alpha channel. Pillow exports the masked RGBA to all ICO sizes.
The build consumes launcher.ico directly; rebuilding the EXE does not need
Pillow or access to the original Downloads folder. Both image files live
alongside this file in src/packaging/windows/.
